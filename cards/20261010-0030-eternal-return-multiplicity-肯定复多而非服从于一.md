# 永恒回归肯定复多，而非服从于一、相同与必然

## 论题展开

永恒回归是肯定的强力，但它肯定的是复多之物的一切、不同之物的一切、偶然之物的一切，而不是使它们服从于一、相同与必然性的东西，也不是一、相同和必然本身（P204）。

## 我的判断

这一表述把永恒回归从必然性的宇宙循环转向复多的肯定。但“肯定复多”若不设限，可能滑向“一切皆可”的相对主义。德勒兹的回应是差异的选择性，但需要一个可执行的判准；卡 20261010-0014 提出的“表象只能回归一次”，可作为这一判准的候选。
