# 沈志中：女人=对象a与性关系的不可能

## 论题展开

沈志中在拉康性化公式中处理女性位置。**女人是对象a**：因为全称的女性性别并不存在，所以对男性而言，女性这边只能是被视为欲望根源的 object a 的一个又一个的女人——女人是 object a，这在人类文化史上并不稀奇：从西方中世纪宫廷之爱的骑士文学中的女士形象，到中国古代的缠足，都是将女人欲望物化的具体表现；虽然现代女人已不再裹脚，却有更先进的整形和化妆技术（甚至虚拟整形软件）让女人更快变成珍贵的、被欲望的 object a。这个性别分化公式显示出男性和女性之间的**不可能的性关系**：因为这两个集合之间不可能有一对一的互映；由于两性关系涉及的是不可能的真实场域，拉康特别强调这些逻辑公式书写的必要性。

**爱情的神话**：爱情始终是相互的（réciproque），但这种相互性显示爱情只是对欲望完全无知的激情——因为人的欲望就是大他者的欲望，所以在爱情中大他者身体的绝爽并非必要且充分的条件；爱情要求的始终是"更多"（encore），那正是欲望辩证中产生的"爱的要求"的深渊。性的绝爽只不过是欲望辩证中意符交换过程产生的剩余价值，即拉康所称的**多余绝爽**。性与话语的交换：有使用价值地，男人像用于繁殖的家畜（种马、种猪）"种人"，但俄狄浦斯的阉割效应使"种人"失去使用价值，成为必须从女人身上寻找绝爽的男人；相对地，女人代表着作为阳具交换价值的阳具绝爽——在人类社会亲属关系中，女人总是作为被交换的项目或礼物，这才女人被物化的真正定义，也解释了女性性质中一个重要特质：**装扮（mascarade）**。

## 我的判断

**"女人=对象a"与"爱情要求更多（encore）"对用户的爱情论是两面**：正面（用户认可的），用户的"重爱之爱"（每瞬间重新爱上）恰恰拒绝把伴侣当作可被占有的 object a——重爱不是把对方物化为欲望根源，而是在每一次"重新爱上"中把对方当作一个新对象相遇（这拒绝"你身上有一个未知数X"的固定化）；反面（用户警惕的），一切激情之爱（柄谷 20260830-0005 批判的）都运行在"伴侣=对象a"的结构里——爱的是对方身上的剩余（超验的 X），而非对方作为单独性。用户"无血缘爱伴侣孩子=放弃位置保留实践"正是对"女人=对象a"的拒绝：爱的实践不物化对方，而保留对方的不可占有（对象a）作为每次重新相爱的契机。

**"性关系不可能，性的绝爽=多余绝爽"对用户"性情境解离=青春期特质"（记忆）提供理论定位**：拉康-沈志中的性关系不是结合而是交换——性快感只是欲望辩证的剩余价值。用户经验（做爱/远程不触发解离=活他者锚定、独处打开）与之吻合：当对方是"活的他者"（不是对象a的替代）时，性关系作为"交换"被真实的相遇取代，hence 不触发解离；当独处/看片时，对象a缺席，欲望只能面向符号系统（能指链），解离打开。这是用户"活他者锚定"的拉康表述：活他者=拒绝把对方对象a化的实践。

边界：沈志中的女性论述是拉康性化公式的移译，带有菲勒斯中心（男人有阳具、女人被定义为对象a）的理论包袱——用户使用"女人=对象a"时应作结构性理解（欲望结构中的对象位置），不把它当作对真实女性的规范描述；用户偏好的无血缘爱恰是超越这一结构的实践（对象a位置被开放的相见取代）。
