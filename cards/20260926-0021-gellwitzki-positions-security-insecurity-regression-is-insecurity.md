# (不)安全即两个克莱因位置；并且：退行本身就是不安全，不是安全与不安全之间的空间

## 论题展开

**双等式的提出（p.4）。** 作者提议把本体论不安全等同于**偏执-分裂位置**，本体论安全等同于**抑郁位置**。克莱因式意义上的"位置"指两种不同的心理关联模式，最终驱动并引导主体行为；两者的差别在于主体如何**经验与管理焦虑**——偏执-分裂位置是"分裂的方式"，抑郁位置是"非分裂的方式"。因此说本体论安全是一个位置，等于说这一概念归根到底指焦虑如何被经验、被管理，以及带来什么社会政治后果。位置不是离散的二元对立，而是**强度谱**：心理是动态的，主体的关联模式随所经验焦虑的强度而不同程度地退行（p.4，引 Klein 1975: 16）。

**与既有克莱因派的分歧（p.13）。** Cash（2017, 2020）、Gellwitzki 与 Houde（2023）、Houde（2024）都把两个位置当作"本体论安全与不安全**之间**的空间"：偏执-分裂的防御机制让主体**避免**陷入不安全，于是"本体论不安全只能逼近而从不真正实现"（p.8）。本文相反：**这种退行本身就是本体论不安全**——一个自我如此不安全，以至于诉诸退行的防御机制来消除复杂、矛盾与不确定，把自我、他者与世界重建成好与坏的二元。同样地，主体诉诸抑郁位置不是"防御不安全"，而是表明它已处在安全位置：自我足够安定，能承受矛盾、能批判自省、能体验内疚与羞愧、并生出发修补的欲望。

**辩护与代价（pp.13–14）。** 辩护是："主体从不本体论不安全"这一断言，恰如拉康式"主体从不本体论安全"，**同样取消了这一概念的必要性与分析效用**。作者保留 Giddens 的"混沌"图景，但把它放到**谱系的极端端**，而非不安全的唯一形式。他给出三条理由：分析上，可用防御机制区分安全与不安全，并提供一个工具箱；理论上，个体与集体主体会经历整个谱系，且**本体论不安全不是使人瘫痪的，而是使行动成为可能的**；规范上，重新解释框架以凸显本体论安全的积极与变革潜能，并承认不安全是适应性的、但可能成问题的关联模式。

**表格要点（p.27）。** 不安全位置：分裂（部分客体）、理想化、否认内疚与责任、去人性化与贬损、（全能式）否认、内摄、投射性认同；主导情感为迫害性焦虑、为自身而恐惧、对自身与内群体的爱、对他者与外群体的恨。安全位置分两极：负极（有限矛盾、有限分裂、内摄/投射性认同的有效限制、"假"修补；情感为抑郁性焦虑、为他者而恐惧、控制/得意/轻蔑、（无意识）内疚）；正极（矛盾、接受内疚与责任、"真"修补；情感为抑郁性焦虑、为他者而恐惧、丧失与哀悼、（有意识）内疚、羞愧、共情、依赖、爱）。

## 我的判断

**判定先行：这次重新归属在一处确实更好——它让"本体论不安全"重新成为一个有工作的概念。** 在"位置之间"读法下，不安全是一个从不被跨越的阈值，因此原则上没有任何证据能算作不安全；在本文读法下，不安全**在话语中可观察**（分裂、去人性化、理想化、内摄与投射性认同），因此可检验。这是实实在在的分析收益。

**但代价需要讲清：概念所指变了，而文章把它写成纠错。** 原读法的动机恰是那个观察——叙述分裂的国家**照样运转**，所以 Cash 与 Houde 把偏执-分裂放在不安全之前。本文承认这一行为（"不安全不是使人瘫痪的，而是使行动成为可能的"），却把它改名为不安全。此后"不安全"不再指自我存续受到的威胁，而指**管理焦虑的一种风格**。两个后果：

（1）**"本体论"一词开始漂浮。** Giddens 那里，它指自我连续性的（受威胁的）状态；在这里需要论证好/坏分裂**威胁存续**。文章以克莱因的"毁灭焦虑"给出这一步，但在国家与群体层面主要靠类比通过，未逐层论证。

（2）**与 Cash/Houde 的分歧部分地是命名之争。** 双方对现象的判断一致，只是标签放在哪里不同。文章自己的辩护（该读法保留分析意义）是关于**效用**而非关于真假的，所以更诚实的说法是：这是一项有收益的约定选择，而不是对一处错误的纠正。这一点值得写下来，因为卡片盒里两派的卡都有——将来引用时不要把它读成"Cash 错了"。

**一处未被文章处理的内部张力。** 按 Gellwitzki 自己转述，Cash 认为个体**可以在偏执-分裂位置上是安全的**（北爱尔兰的敌友意识形态持有者），也可以被另一种意识形态威胁（p.9）。若这一点成立，"安全＝抑郁位置"的等式就被它所依据的那支文献否证了。文章以"Cash 在两种表述之间摆动"带过，但这里其实需要正面论证：一个在分裂中感到安全的自我，是否只是把不安全的证据当成了安全的证据。
