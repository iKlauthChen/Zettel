# 疑问卡：概念提出时须辨明「剩余」所属脉络——surplus 为主线，residue 一支的三种读法及其与剩余价值的接触与排除

## 问题

剩余安全的头词取 surplus，英文统一为 surplus security，residual security 已在 skill 中排除。但 surplus 与 residue 在中文同作「剩余」，概念提出时若不标明所属脉络，读者会把统计残差、神学余民或文化残存误读为剩余安全的机制。问题分三层：其一，residue 一支内部有哪些互不相通的读法；其二，它们与剩余价值在何处接触、在何处排除；其三，从中可取什么养分，又如何避免混同。

## 主线：surplus 脉络

剩余价值（Mehrwert）是增殖的增量，可计量、可占有、可减。剩余安全的案例（覆盖面积、指标增殖）讨论的正是可计数的增量与可减性，故以 surplus 为主线有案例依据。须注意，拉康的 plus-de-jouir 借自 Mehrwert，却在 surplus 脉络内得到负量：它是额外多出的缺口，不可减，也不随积累增长。借用这一概念时，须标明它属于缺口一类。

## residue 一支的三种读法（待核）

一、统计残差（residual）。模型解释之后剩下的误差，属认识论概念，判断标准是拟合度，原则上可通过改进模型消除。借用它，剩余安全便成为方法缺陷，与「结构性不可消除」的主张相反，应当排除。

二、余民（remnant／resto）。阿甘本借保罗书信的神学词汇讨论分裂之后仍然留存的东西，它既不属于全体，也不属于被排除者，标示秩序的构成性边界。它不随生产增长，也不可计量。借用它可以说明边界的功能位置，但会使剩余安全失去经济机制，滑向弥赛亚式剩余。

三、文化残存（residual）。威廉斯与 dominant、emergent 并列，指旧形态在当下的延续。它是时间性概念，与空间机制无直接关系，但提示遗留物可以随时间留存，而不只随规模或分辨率增多。

## 与剩余价值的接触与排除

接触一：生成。两者都相对于一次闭合操作而定义（资本循环的闭合，同质化的闭合）。排除在于：剩余价值是价值增殖的过程产物，残余物是度量或分类之前即已产生的盲区。

接触二：可减性。剩余价值可以被占有、让渡与对抗，其量在账上可减。残余物从未进入计数，故不可减，只能被指认或排除。这一条决定「减去剩余即失去快感」能否转用，也是三种读法中排除最强的一条。

归属。剩余价值有占有者（资本、主人、国家）；残余物只有位置而无持有者。20260621-0485 的警告在此适用：把残余物实体化为某一群体的身份，位置的结构功能即告失效。

时间性。剩余价值随积累增长；残余物随编码的分辨率或覆盖的规模增长，而非随产量增长。20260709-0002 与 20261103-0003 各提供一例，两者的证伪方式不同。

## 可取的养分

统计残差的诊断功能可转为方法：模型解释不到之处即是剩余所在，据此可设计可证伪的观察点，但须防止把它当作可消除的误差。余民的边界功能可用于解释剩余安全中空间边界的作用，不必依赖量的过剩。文化残存的时间滞留可与斯蒂格勒的第三滞留对照，待核。不随产量增长的遗留物，为抽象简化的分辨率机制提供了依据。

## 待定的使用规则（草案，未定）

一、概念提出时，标明所借脉络（surplus 主线，或 residue 一支中的某一读法），并写明该概念在生成、可减性、归属与时间性四项上与剩余价值的差异。
二、中文上，residue 一支用「残余」或「余项」，统计残差用「残差」，避免与「剩余」同形。
三、英文上，剩余安全头词用 surplus security，不用 residual security。

以上规则是草案，是否采用、如何措辞，由用户定。
