# 编码可组织图像，却可能抵消绘画的感觉张力

## 论题展开

德勒兹区分了编码的几种操作：抽象元素的内在组合；与参照整体保持同形、产生信息或叙述的组合；以及把外在元素编码化，使之能由编码内部自动复制。第三种操作可见于电脑生成肖像等形象化数据。

编码的风险在于它可能停留于智性组织，缺乏对神经系统的直接作用。德勒兹借培根批评某些抽象绘画：张力被内化为视觉形式，反而被形式抵消；编码过于抽象时，也可能退化成简单的象征编码。

## 我的判断

这段区分没有把代码一概排除在绘画之外，而是追问编码究竟组织了什么、又产生何种身体效果。由此，抽象形式并不自动摆脱再现：它仍可能按固定代码运作，让观者识别规则，却不受感觉冲击。边界在于，德勒兹对编码的判断依赖「是否直接作用于神经系统」这一标准；在此处，他尚未提供独立的检验方法，故不能仅凭作品使用计算机或抽象形式便判定其缺少感觉。
